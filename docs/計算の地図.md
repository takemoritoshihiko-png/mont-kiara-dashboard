# 計算・表示判断の入口

2026-10-21。地図復旧と構造整理の対象。業務計算・保存形式は変更しない。

| 問い | 答えの型・欄 | 唯一の入口 | 材料・境界 | 不明の扱い |
|---|---|---|---|---|
| 2地点の距離は何kmか | number (km) | `src/domain/geo.js` `haversineKm` | 読込済み緯度経度。地図・周辺検索が共有 | 座標欠落は呼出側で対象外 |
| 地図上でピンが重なるか | 半径m / boolean | `src/domain/markerLayout.js` `overlapRadiusM` / `nearAnyMall` | 縮尺・緯度・アイコン幅・表示中のモール | 座標やモールなしは false |
| 同地点のピンをどこへ表示するか | Map<key,{dx,dy}> (px) | 同上 `spotOffsets` | 表示対象のレコード、既存の3m・20px・種別優先順 | 座標欠落は除外。保存座標は変更しない |
| 背景地図をどこから取得するか | URL・attribution・maxZoom | `src/data/basemap.js` `BASEMAP` | Leaflet `initMap` が参照 | 通信成功でも地図画像の実画面確認が必要 |
| 記録を統合したとき何を残すか | 個人記録の7欄 `w/v/vd/rv/m/amt/h` | `src/data/personal.js` `mergeStores` → `mergeEntry` | `normalizeEntry` が入力を正規化。空欄では既存値を消さず、フラグは片方が1なら保持 | 非表示`h`も他フラグと同じ。非表示解除は既存の復元操作で行う |
| 周辺に何件あるか | 距離帯ごとのtotal/counts/byLayer | `src/domain/nearby.js` `nearby` | 座標のあるレコード。除名`delisted`は数・一覧から除外 | 座標欠落は除外。古いURLや直接選択も`info.js`で除名を拒否 |

同一地点の選び直しは30m以内という既存条件を維持し、距離の再実装をせず `haversineKm` を使用する。
その他の既存機能の担当表は [CODEBASE-MAP.md](CODEBASE-MAP.md)、金額・学費・個人記録の契約は [AGENTS.md](../AGENTS.md) を参照。
