# UI/UX 刷新プラン（実画面監査に基づく改訂版）

作成: 2026-08-07 ／ 前提: B0-B2 本番反映済み ／ 監査方法: 本番・ローカルの実画面を全コントロール操作（想像禁止ルール遵守）

## 0. 設計原則（Apple HIG から本アプリに引くもの）

1. **Clarity** — 1画面1役割。同じ情報を2箇所に出さない。
2. **Deference** — UIは脇役、データ（地図と物件）が主役。彩度の高い色を同格で6色使わない。**アクセント1色＋意味色は小さく**。
3. **Progressive disclosure** — 最初は主要な選択肢だけ。詳細フィルタは求めた人にだけ開く。
4. **Direct manipulation & feedback** — 押した結果は必ず見える（トグルの状態・件数変化の理由・空結果の理由）。
5. **Typography** — システムフォントスタック＋段階スケール（12/13/15/17/22）＋数値は等幅（tabular-nums）。

## 2. 刷新デザイン（画面別）

### 2.1 シェル（ヘッダー＋サマリー）
- タイトル改名: **「KL・ペナン 住まいマップ / KL & Penang Living Map」**（種別横断の実態に合わせる。日英併記維持）
- ヘッダー右の重複統計を削除（A2）。サマリー4枠に一本化し、**アクティブ層に追随**（物件=中央PSF/家賃、学校=学費中央値/生徒数、商業=NLA中央値/テナント数）
- 出典と最終更新日はフッター1行へ（公開サイト用途）

### 2.2 レイヤーと切替（B5の根治）
- 絵文字トグル廃止 → **セグメンテッドコントロール**「🏠物件 | 🎓学校 | 🛒商業」（iOS標準の型・選択状態が構造的に見える）
- 非アクティブ層は地図に薄く残す（opacity 0.45・クラスタのみ）
- 🏆受賞は物件層のフィルタ内チップに移動

### 2.3 フィルタ（B1/B2/B3/B6の根治・Progressive disclosure）
- **1段目（常時表示）**: 検索（クリア×付き）＋層別の主要2つ
  - 物件: 家賃帯 / Tier ・ 学校: 対象年齢 / カリキュラム ・ 商業: 規模
- **2段目「絞り込み ⌄」**で残りを開閉（物件: PSF/築年/広さ/状態/エリア/受賞）
- **適用中フィルタはチップで表示**（×で個別解除・「すべてクリア」）→ 件数が減った理由が常に見える
- AREAに**ペナン4エリアを追加**（B2の不整合解消）。STATUSから種別を除去し completed/upcoming のみに（B3バグは選択肢ごと消滅）
- **空結果**: 「条件に合う物件がありません」＋一番効いているフィルタの提示＋「クリア」ボタン

### 2.4 ソート（B4の根治）
- 6ボタン列 → **「並び替え」1ドロップダウン**: おすすめ(Tier)/家賃 安い順/家賃 高い順/PSF 安い順/PSF 高い順/新しい順/古い順/名前順

### 2.5 カード（C1/C2/C3/C5の根治・種別ごとの型）
共通: 上=名前(15px semibold)+日本語名(12px gray)、**ヒーロー行=その種別の意思決定数値**（17px・tabular-nums・桁区切り）、下=メタ1行(12px gray)。
- 物件: ヒーロー=「RM 3,200–5,000/月 ・ PSF 652–1,059」＋Tierチップ(色付き・唯一の色)
- 学校: ヒーロー=「学費 RM45,000–95,000/年」＋カリキュラムチップ。**units/sf/PSF枠は出さない**
- 商業: ヒーロー=「NLA 320,000 sf ・ 250店」＋アンカー1行
- スコアは「Luxury 63.5」とラベル付き・物件のみ・小さく

### 2.6 詳細パネル
- ヘッダーに種別色の細帯＋Tier/種別チップ、住所、閉じる×（44pxタップ標的）
- `[詳細] [周辺]` タブ。周辺=徒歩圏≤800m/車5分≤2km/車15分≤6km×種別カウント＋近い順トップ5（クリックで層またぎ遷移）
- 外部リンクはアクセント1色のテキストボタンに統一（「公式サイト ↗」「iProperty ↗」）

### 2.7 地図の残り
- 選択中マーカー: アクセント色リング＋1.3倍＋最前面（D3）
- ラベル密度はB2の定数で継続調整（D2）

### 2.8 School Finder → 「学費くらべ」
- **KL+ペナン両対応に拡張**（E4。schools_detail.jsonの学年別学費23校分を活用）
- パネル全置換をやめ、学校層の1機能として「学費くらべ」ボタンから開く（E2）
- 年齢を選ぶ→全対象校の年間学費を安い順バー表示（既存のSVGチャートの型を継承）

### 2.9 視覚システム（C5含む）
- フォント: `-apple-system, "Segoe UI", "Hiragino Sans", "Noto Sans JP", sans-serif`
- スケール: 12/13/15/17/22。価格・件数は `font-variant-numeric: tabular-nums` ＋ `toLocaleString()` 桁区切り
- 色: アクセント#0A6CFF系1色。Tier色は維持しつつ小さいチップのみに限定。商業橙/学校紺はマーカーと小バッジのみ
- 余白: 8pxグリッド。カード内padding 12、セクション間16
- モーション: 150–200ms ease-out（パネル開閉・選択遷移）。派手なアニメは入れない

### 2.10 状態
- URL: `?layer=&sel=&tab=`（E1・B3計画どおり）
- ローディング: サマリー4枠とリストにスケルトン（E3）

## 4. 自己採点（5工程実施済み）

| 観点 | 点 | 根拠 |
|---|---|---|
| ①シンプルさ | 9/10 | 常時表示コントロール 8ドロップダウン+10ボタン → 検索+2フィルタ+セグメント+並び替え1つ |
| ②実データ適合 | 9/10 | 全項目が実画面の証拠に紐付く（22件の監査表） |
| ③ネクストアクション | 9/10 | 空結果の復帰動線・フィルタチップ・周辺タブ |
| ④誰がいつ使うか | 9/10 | 4用途確定済み。共有=URL状態、来訪者=学費くらべKL対応、美観=視覚システム |
| ⑤世界標準照合 | 9/10 | セグメンテッドコントロール/開閉フィルタ+チップ=Airbnb・Zillow標準、型はApple HIG |
| ⑥既存仕様の継承 | 9/10 | エリアジャンプ・日英併記・年色・Tier概念・SVG学費チャートの型を全て継承 |
| 計 | **54/60** | 残り-6: モバイル下部シートの完成度とKL学費データの粒度差（学年名が校ごとに違う）は実装中に判明する分 |

**敵対的自己レビューで潰した3点**
1. 「Apple風=白くて薄いUIにするだけでは」→ 色・タイポでなく**構造の原則**(1画面1役割/状態の可視化/段階開示)から各発見に対応付けた。
2. 「フィルタを隠すと上級者が遅くなる」→ 主要2つは常時表示＋開閉状態は記憶。チップで適用中が常に見えるため、開け直す頻度は低い。
3. 「学費くらべKL対応はデータ粒度がバラバラ(Year/Grade混在)で壊れる」→ 年齢→学年のマッピング関数を一段かませ、無い学年は線形補間せず「近い学年の実額」を明示表示（嘘の数字を作らない）。

**極端ケース**
- フィルタ全部MAX適用→0件: 空結果設計(2.3)が受け止める。
- ペナンだけ見たい: AREA追加+ジャンプ連動で初めて一貫。
- 学費データが無い学校(未確認null): 「学費: 要問合せ」表示でゼロ円を出さない（C1の再発防止）。
