## 0. 確定済みの前提（竹森氏裁定 2026-08-07）

- **C案「1アプリ2モード」**: 同じ地図・データ層・周辺エンジンを共有。「住まいモード」では飲食は周辺レイヤー、「外食モード」では台帳v9の全機能を維持。
- **必須要件6つ**（メモリ project_mont_kiara_dining_requirements が正）:
  1. 訪問したか/していないか ② また訪問したいか ③ 1人あたりの予算 ④ 感想 ⑤ 訪問済み一覧 ⑥ 食事カテゴリで選べる
  - ①②③⑤は台帳v9実装済み=**継承**。④はメモ1行→複数行に拡張。⑥が新規。
- 元データ: `kl-dining-ledger-v9.html`（デスクトップ・50店・全項目埋まり・**緯度経度なし**）

## 1. フェーズ構成

### D1: 座標取得（最初のゲート）
- 50店の Google Place ID + 住所から緯度経度を取得。
- 方法: Nominatim(店名+KL)→照合、失敗分は住所ジオコーディング→エリア(ar)との整合チェック。Google Geocoding APIは使わない(キー管理を増やさない)。
- 検証: 全50件がKL域内(lat 2.9-3.4)・エリア名と方角が矛盾しない・重複座標なし。**取れない店は保留リストへ**(地図に出さずリスト表示のみ)。
- ここが失敗したら以降を止めて報告(リスト止まり案に切替裁定)。

### D2: データ移植
- v9のJS配列 `D[]`(20項目) + VOX(賛否抜粋) → `restaurants.json` へ変換(1ファイル・UTF-8・LF)。
- スキーマ: id(R0001形式・安定ID)、name/nameJa/cat/catGroup/michelin/rating/reviewCount/venue/venueType/area/address/placeId/lat/lng/priceLunch[lo,hi]/priceDinner[lo,hi]/priceNote/editorNote/vox{pros,cons}/extraFlags/kidOk/natCode。
- 整合性テスト追加: 50件・id一意・座標域内・価格lo<=hi・カテゴリは定義済みcatGroupに全件属す・ミシュラン値enum。
- **v9原本はデスクトップに残置**(移行完了を竹森氏が確認するまで消さない)。

### D3: 住まいモードへの飲食レイヤー
- セグメントに「🍽 飲食」を追加(4層目)。
- カード型(ヒーロー行=種別の意思決定数値): 「昼 RM30–60 ・ 夜 RM120–250」+ミシュランバッジ(🌟2/🌟1/ビブ/セレクト)+カテゴリチップ。
- フィルタ: **カテゴリ大分類(要裁定・下記)** / ミシュラン / 価格帯 / エリア / 子連れ可。
- 周辺タブに飲食が自動参加(nearby エンジンは層非依存のため追加実装ほぼゼロ)。
- 物件詳細の周辺に「徒歩圏: 星付き2・ビブ3」等が出る=住まい選び側の価値。

### D4: 外食モード
- ヘッダーにモード切替(住まい/外食)。外食モード=飲食層固定+個人記録UIが出現:
  - 訪問済トグル / 再訪3択(また行く・機会があれば・もういい) / 実額入力(RM) / **感想(複数行textarea・v9の1行から拡張)**
  - 訪問済み一覧タブ(再訪意向でグループ化・実額平均表示) = v9「Log」タブの継承
  - VOX(賛否抜粋)・価格注記・編集メモの表示 = v9カードの情報密度を維持
- 個人記録: localStorage(キー `mkd_dining_personal_v1`)+JSONエクスポート/インポート/全削除。**公開サイトでも他人には見えない**(各自のブラウザにのみ存在)ことをUIに明記。
- v9のスコア式(縮約★)と「レビュー母数の厚さ」表示は継承。

### D5: 検証・本番
- 全テストgreen+実画面(4層切替・外食モード・個人記録の保存/復元/エクスポート)+モバイル幅。
- 段階公開: まず飲食層(D3)だけ本番→確認後に外食モード(D4)。

## 2. 裁定結果【竹森氏 2026-08-07 確定】

- **裁定1: カテゴリ大分類=8分類案で確定**（下表）。
- **裁定2: 拡充方向=「評判」軸で確定** — ミシュラン/ビブグルマン/Google高評価など「とにかく評判が良い美味しい店」を基準に拡張する。居住圏かどうかは優先軸にしない。
- **裁定3(追加): チェーン店は加味しない**（IPPUDO/Sakae Sushi等はP3のまま対象外）。
- **裁定4(関連・本体側): upcoming物件の価格は現状どおり非表示**。

### 裁定1で確定したカテゴリ大分類(8分類・実データ50件を集計済み)
| 大分類 | 件数 |
|---|---|
| マレーシア料理 | 12 |
| 洋食・グリル | 10 |
| 中華 | 6 |
| インド・スリランカ | 6 |
| 鶏飯・ご飯もの | 5 |
| 麺・肉骨茶 | 5 |
| 日本・その他アジア | 5 |
| 屋台街 | 1 |

論点: 「中東」が"日本・その他アジア"に入るのは無理がある(件数増なら独立)。「屋台街」1件は分類として弱い。**代替案**: 7分類(屋台街を「マレーシア料理」へ吸収)。

### 裁定2: 拡充の優先方向
現50店はミシュラン系中心(完成度10-20%との自己評価)。次に足すのは:
- (a) モントキアラ/デサパークシティの日常店(住まいモードとの相乗り最大)
- (b) ミシュラン網羅の完成(外食モードの網羅性)
- (c) 現状維持で機能だけ先に(データはあとから)
